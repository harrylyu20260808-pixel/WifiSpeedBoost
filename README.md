# WiFi 优化提速工具箱

一个像 [MAS](https://github.com/massgravel/Microsoft-Activation-Scripts) 一样的 Windows 命令行（.bat）交互式工具箱。
帮你**诊断 WiFi 网络问题、测速、优化提速**，还内置了几个 CLI 小游戏消遣。

纯 .bat 实现，双击即用，无需安装任何依赖。**中英双语可选**。

## 功能一览

| 菜单 | 功能 | 说明 |
|---|---|---|
| 1 | WiFi 网络体检 | 读取信号/速率/信道，自动评价并给优化建议 |
| 2 | WiFi 连接详情 | 显示网卡连接信息 + IP 配置 |
| 3 | 附近 WiFi 扫描 + 信道分析 | 看 2.4G 信道拥挤度，教你怎么换不重叠信道 |
| 4 | 网络延迟测试 | Ping 网关 / 外网 / DNS，判断是否卡顿掉包 |
| 5 | 一键优化加速 | 清 DNS 缓存、TCP 自动调优、释放带宽、自动开启位置服务（需管理员） |
| 6 | 优化建议指南 | 路由器摆放、信道选择、5G 优先等建议清单 |
| 7 | HTTPS 链接测速 | 从多个 HTTPS 站点下载测速，区分宽带慢还是某网站 CDN 慢 |
| 8 | 断点续传下载器 | 用 curl 断点续传下载任意 HTTPS 文件 |
| 9 | CLI 小游戏 | 猜数字 / 石头剪刀布 / 掷骰子 / 猜硬币 |

## 使用方法

```bat
双击 WiFi优化提速工具箱.bat
```

- 首次运行选择 **中文 / English**
- 读取 WiFi 信号/信道需开启系统**位置服务**（菜单 5 可自动开启）
- 菜单 5 需要**管理员权限**（UAC 点“是”）
- UTF-8 编码（内置 `chcp 65001`），任意 Windows 中文显示正常

## 从源码构建

```bat
python make_wifi_bat.py
```
