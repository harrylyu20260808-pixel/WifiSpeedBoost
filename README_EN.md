A pure `.bat` Windows command-line WiFi toolbox: **Diagnose · Channel Analysis · Latency Test · One-click Optimize · HTTPS Speed Test · Resume Downloader · CLI Mini Games**. Double-click to run — no installation, no dependencies, built-in Chinese/English bilingual UI.

## ✨ Features

- ⚡ **One-click Boost**: flush DNS cache, enable TCP auto-tuning, disable network throttling — release bandwidth the system is holding back
- 🔍 **WiFi Health Check**: reads signal strength / speed / channel / link quality, auto-rates and gives targeted advice
- 📡 **Channel Analysis**: scans nearby WiFi usage, tells you to avoid crowded 2.4GHz channels (1 / 6 / 11 recommended)
- ⏱️ **Multi-site HTTPS Speed Test**: Cloudflare + OVH multi-source downloads — see at a glance whether your broadband or a site's CDN is slow
- ⬇️ **Resume Downloader**: curl `-C -` resume support, keep downloading after an interruption
- 🎮 **CLI Mini Games**: guess the number / rock-paper-scissors / dice / coin flip — fun while waiting for speed tests
- 🌍 **Bilingual UI**: switch 中文 / English at first run, instantly across the whole interface
- 📄 **Zero Dependencies**: pure .bat + built-in Windows commands (netsh / ipconfig / ping / curl), nothing to install

## 🚀 Quick Start

1. Download [`WiFi优化提速工具箱.bat`](WiFi优化提速工具箱.bat)
2. **Double-click to run** (Windows 7 / 10 / 11)
3. Pick a language on first run, then operate by menu numbers

> [!NOTE]
> - Reading WiFi signal / channel info requires the system **location service** (menu 5 enables it in one click, or manually: Settings → Privacy & security → Location)
> - Menu 5 "One-click Optimize" needs **administrator rights**; a UAC prompt will appear — click "Yes"
> - The file is **UTF-8 encoded** (built-in `chcp 65001`), so menus render correctly on any language Windows

## 🧩 Feature Details

| Menu | Feature | Description |
| --- | --- | --- |
| 1 | WiFi Health Check | Reads signal / speed / channel, auto-rates and gives optimization advice |
| 2 | WiFi Connection Details | Shows adapter connection info + IP configuration |
| 3 | Nearby WiFi Scan + Channel Analysis | See 2.4G channel congestion, switch to non-overlapping channels |
| 4 | Network Latency Test | Pings gateway / internet / DNS to detect lag or packet loss |
| 5 | One-click Optimize | Flush DNS, TCP auto-tuning, release bandwidth, auto-enable location service (admin required) |
| 6 | Optimization Guide | Router placement, channel selection, 5G priority checklist |
| 7 | HTTPS Link Speed Test | Cloudflare 25MB + OVH 10MB / 100MB multi-source downloads |
| 8 | Resume Downloader | curl `-C -` resume downloads for any HTTPS file |
| 9 | CLI Mini Games | Guess the number / rock-paper-scissors / dice / coin flip |

## 🛠️ Build from Source

The core is generated by `make_wifi_bat.py` (outputs a bilingual bat as UTF-8 + CRLF, so Chinese menus render correctly on any language Windows):

```bat
python make_wifi_bat.py
```
